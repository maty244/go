# 02 — Control de flujo

## Objetivo

Controlar qué instrucciones se ejecutan y cuántas veces. Requiere funciones,
variables y operadores de `01_fundamentos`.

## Recorrido

`if` → `switch` → `switch` sin expresión → las tres formas de `for` → `break`
y `continue` → labels → `range` moderno.

El `for` clásico se conserva porque aparece en mucho código. Desde Go 1.22,
`range` también puede recorrer enteros.

## Prerrequisito y reto

Requiere `01_fundamentos`. Resolvé `retos/` y después compará `soluciones/`.
