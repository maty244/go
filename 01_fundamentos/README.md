# 01 — Fundamentos

## Objetivo

Aprender a representar valores, operar con ellos y dividir un programa en
funciones pequeñas. Solo requiere haber completado `00_inicio`.

## Recorrido

Variables → constantes → tipos → zero values → conversiones → declaraciones →
operadores → `fmt` → funciones → retornos múltiples → scope → comentarios →
errores comunes.

La lección `19_dinero_con_enteros` fija una regla para el resto del curso:
`type Dinero int64` representa centavos. `float64` queda para medidas,
porcentajes y para aprender aritmética de punto flotante, no para cobrar.

con `soluciones/`.
