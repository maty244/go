# 09 — Biblioteca estándar

## Objetivo

Aprender los contratos y paquetes que aparecen constantemente en programas
reales, antes de incorporar dependencias externas.

## Orden

1. `01_io`: `io.Reader`, `io.Writer`, buffers y streaming.
2. `02_archivos`: archivos, CSV, temporales, `filepath`, entorno y `os.Root`.
3. `03_json`: codificación, tags, opcionales y datos dinámicos.
4. `04_tiempo`: instantes, duraciones y timers.
5. `05_contexto`: cancelación y deadlines.
6. `06_logging`: logging estructurado con `slog`.

## Prerrequisito y reto

Requiere las etapas `01` a `08`. Resolvé `retos/` y compará `soluciones/`.
